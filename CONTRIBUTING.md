# Contributing

Contributions should improve a concrete engineering workflow or its verification. Explain the problem and provide reproducible evidence. Avoid copying material from other projects without permission. Prefer precise language, executable examples, and focused modifications over broad new rules.

Before proposing a change:

1. Explain the problem and the observable outcome.
2. Show which existing instruction or reference is insufficient.
3. Add or update tests when behavior or helper scripts change.
4. Run the package validator and unit tests.
5. Update the manifest after final edits.

Do not commit environment files, credentials, private repository material, test reports containing secrets, or generated caches. Keep platform-specific behavior optional and documented with its prerequisites.
